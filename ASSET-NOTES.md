# Asset notes

- `assets/id.png` and `assets/right_pointing.png` are the user-provided generated character assets. They are embedded inline into the SVGs as base64 PNG data.
- `InterDisplay-Bold.woff2` is converted from the system Inter font package; license is included at `assets/fonts/Inter-LICENSE.txt`.
- `DejaVuSansMono.woff2` is converted from DejaVu Sans Mono; license is included at `assets/fonts/DejaVuSansMono-LICENSE.txt`.
- SVGs contain no external image, font, CSS, JavaScript, or network request.
- Stack orbit nodes use compact labelled monogram marks rather than remote icon URLs so the SVG remains self-contained.
