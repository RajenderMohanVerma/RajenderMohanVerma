### 🅿️ SmartPark — Smart Parking Management System

A full-stack parking management platform developed as an **MCA Minor Project**. It manages the complete parking lifecycle — from discovering and reserving a parking slot to QR verification, check-in/check-out and digital receipts.

**Key Features:**
- 🔐 User registration, login and account management
- 🚗 Vehicle garage with multiple vehicles
- 🅿️ Parking area and live slot search/filtering
- 📅 Slot reservation with fee estimation
- 📱 Secure QR pass generation and verification
- 🧾 Digital PDF receipt generation
- 🔔 Notifications and payment history
- 👨‍💼 Admin area and slot management
- ✅ Parking check-in/check-out and payment ledger
- 📲 Responsive PWA with dark/light mode

**Tech:** Python, Flask, SQLAlchemy, PostgreSQL/Neon, SQLite, Bootstrap, JavaScript, QR/PDF generation, Vercel

🔗 **Live Demo:** https://smart-parking-three-henna.vercel.app/

🔗 **GitHub:** https://github.com/RajenderMohanVerma/SmartParking

<!-- PROJECT 2: Kabadivala -->
### ♻️ Kabadivala — Traceable Recycling Platform

A role-based recycling platform designed to connect **customers, e-waste collectors, collection hubs, recyclers and administrators** in one traceable workflow — from pickup request to recycling completion and certificate generation.

**Key Features:**
- 👤 Role-based workspaces for Customer, Collector, Hub Manager, Recycler and Admin
- 📦 Pickup booking with item details, images and scheduling
- 📷 Camera-first/manual image upload
- 🤖 Gemini-assisted item identification
- 🚚 Collector matching based on availability, category, capacity and service area
- ⚖️ Pickup proof and actual-weight capture
- ⭐ Eco points, reviews, complaints and notifications
- 🏭 Hub inventory and batch management
- 🔗 QR-based handoffs and chain-of-custody tracking
- ♻️ Recycler processing stages and recovered materials
- 📜 Recycling certificate generation
- 📊 Admin analytics, audit logs and operational management
- 📱 Responsive React interface with PWA support

**Tech:** React, Vite, React Router, Node.js, Express.js, PostgreSQL, Prisma, JWT, Zod, Multer, Gemini Vision API, PDF/QR generation, Vercel, Render

🔗 **Live Demo:** https://kabadiwala-26.vercel.app/

🔗 **GitHub:** https://github.com/RajenderMohanVerma/Kabadiwala

A professional **Flask-based Alumni Management System** designed to connect students, alumni and faculty through networking, career opportunities, messaging and intelligent recommendations.

**Key Features:**
- 👥 Multi-role system for Students, Alumni, Faculty and Admin

- 💬 Public and private real-time messaging using WebSockets
- 🧠 Hybrid recommendation engine using rule-based scoring + ML collaborative filtering
- 🤖 KNN-based recommendations with cosine similarity

- 📧 OTP verification and email notifications

- 📊 Admin analytics and CSV reporting

**Tech:** Python, Flask, Flask-Login, Flask-SocketIO, SQLite, scikit-learn, NumPy, Bootstrap, CSS, JavaScript
